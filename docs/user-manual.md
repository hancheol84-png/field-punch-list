# 현장 펀치리스트 사용 안내

## 동 추가·수정

세대 영역의 숫자 동 버튼을 누르면 입력할 동을 선택합니다. 동 목록을 여러 개 추가하거나 바꾸려면 화면 아래 **현장 세팅**을 엽니다. 모바일과 컴퓨터의 조작 순서는 같습니다.

1. 화면 아래로 이동해 **현장 세팅**을 펼칩니다.
2. **동 (쉼표로 구분)** 입력칸에서 기존 동을 유지하고 새 동을 덧붙입니다. 예를 들어 `101, 102, 103, 104`를 넣으면 동 버튼 4개를 표시합니다. 쉼표는 영문 `,`를 사용하고 같은 동은 한 번만 넣습니다.
3. **세팅 저장**을 누릅니다.
4. 위쪽 **세대** 영역에서 추가한 동 버튼을 확인하고 선택합니다.
5. 호수를 입력하고 **이동**을 누른 뒤 항목을 작성합니다.

시범운영 앱에서는 **서버 저장 완료**까지 확인합니다. 같은 계정으로 다른 기기에서 로그인하거나 **최신 기록 불러오기**를 누르면 저장한 동 목록을 가져옵니다. 다른 계정의 동 목록에는 영향을 주지 않습니다.

### 동 하나를 빠르게 추가

세대 영역의 동 번호 옆 **＋**를 누르고 입력창에 새 동 번호 하나를 넣어 확인합니다. 같은 동을 중복해 넣을 수 없습니다. 입력창이 보이지 않거나 여러 동을 한꺼번에 등록하려면 위의 **현장 세팅** 방법을 사용합니다.

### 저장이 안 될 때

- 동 번호를 하나 이상 넣었는지, 같은 동이 중복됐는지 확인합니다.
- **현장 세팅** 안에 표시된 경고를 읽습니다. 코어 설정 등 다른 설정이 잘못돼도 함께 저장하지 않습니다.
- 작성 중인 내용이 있다면 현재 선택한 동을 목록에서 빼기 전에 내용을 등록하거나 비웁니다.
- 서버 연결 오류는 **서버 저장 다시 시도**로 재전송합니다. 다른 기기에서 설정을 먼저 바꿨다는 안내가 나오면 미전송 내용을 엑셀로 보관한 뒤 화면 안내에 따라 최신 기록을 가져옵니다.
- 동 목록 변경은 기존 작성 항목의 동 번호를 바꾸지 않습니다. 기존 항목의 동 번호는 해당 항목의 **수정**에서 바꿉니다.

실기기 필요: 휴대폰에서 세팅 입력·저장, 같은 계정의 휴대폰과 컴퓨터 사이에서 변경된 동 목록 조회.
