# 현장 펀치리스트

휴대폰으로 세대 보수 요청을 말하거나 눌러서 입력하고 엑셀로 받는 정적 웹 도구입니다. 서버·로그인·통계·외부 라이브러리·CDN을 사용하지 않습니다.

## 사용 순서

1. 동 버튼과 숫자판으로 호수를 지정하고 **이동**을 누릅니다. 음성으로 동·호수를 바꾸지 않습니다.
2. 위치를 선택하고 공종은 **자동 분류** 또는 직접 선택합니다. 직접 선택한 공종은 바꿀 때까지 유지됩니다.
3. 내용을 입력하고 **한 줄 추가**를 누르거나 음성으로 말합니다. 입력 중 초안도 기기에 저장합니다.
4. **전체 엑셀 받기 (.xlsx)**를 누른 뒤 파일 앱 또는 다운로드 폴더에서 파일을 확인합니다. “받기 요청” 표시는 실제 저장 완료 확인이 아닙니다.

엑셀은 전체 시트와 공종별 시트로 구성됩니다. 열은 점검일·동·코어·호수·위치·공종·내용·확인사항이며, 동 → 코어 → 층 내림차순 → 호수 순서입니다. 현장명·점검인은 현장 세팅에서 기기에만 입력할 수 있습니다. 시각이 없는 기존 기록은 날짜 미상으로 표시합니다.

## 저장과 삭제

- 기록·초안·세팅은 이 주소의 브라우저 `localStorage`에만 저장합니다. 서버로 전송하지 않으며 다른 기기와 자동 공유하지 않습니다.
- 행의 입력 시각 기준 **7일(168시간)**이 지나면 앱 시작·화면 복귀·사용 중 점검 시 삭제합니다. 앱이 닫혀 있을 때는 실행할 수 없으므로 다음 실행 때 정리합니다. 삭제 3일 이내에 남은 일수를 안내합니다.
- 이미 받은 엑셀, 입력 중 초안과 세팅은 이 자동 삭제 대상이 아닙니다. 날짜 미상 기록은 임의로 삭제하지 않습니다.
- 브라우저 데이터 삭제·비공개 모드·저장 공간 부족·장기간 미사용 정책으로 7일 전에도 기록이 사라질 수 있습니다. 매일 엑셀로 받아 두세요. Safari 탭과 홈 화면 앱 사이에 저장소가 공유되지 않을 수 있습니다.
- 저장 실패 경고가 보이면 화면을 닫기 전에 기록을 엑셀로 받고 초안을 별도 보관하세요.
- 저장 키는 `punchlist.v2`, `version: 4`입니다. 버전 2·3의 기록·초안·세팅을 읽고 다음 저장 때 버전 4로 보존합니다. 이전 앱은 새 저장 형식을 읽지 못하므로 업데이트한 버전에서 사용하세요. 읽을 수 없는 형식은 덮어쓰지 않고 원본 JSON 받기를 제공합니다. 이전 시험 주소의 기록은 브라우저 보안 경계 때문에 읽지 않으며 이전 기능은 없습니다.
- 날짜·자동 삭제는 기기 시계를 사용합니다. 시계가 잘못되면 표시·삭제 시점도 달라집니다.

## 음성과 오프라인

- 브라우저 `SpeechRecognition`을 사용합니다. 브라우저가 음성을 인식 서비스로 전송할 수 있습니다. 앱 자체는 녹음 파일을 저장·업로드하지 않습니다.
- 아이폰과 지원되지 않는 브라우저는 입력 칸의 **자판 마이크**를 이용하세요. 인식률과 연속 듣기는 기기·소음·네트워크에 따라 다릅니다.
- 첫 접속은 인터넷이 필요합니다. **오프라인 준비 완료** 표시 후 같은 브라우저에서 다시 열면 입력·엑셀 받기가 가능합니다. 음성 인식은 오프라인에서 제한될 수 있습니다.
- 새 버전은 화면 안내의 **저장 후 새로고침**으로 적용합니다. 저장에 실패하면 적용을 보류합니다.

## 실행과 시험

설치 작업 없이 기존 Node.js, Playwright, Chrome, Python, openpyxl을 사용합니다. 경로가 별도로 설치되어 있으면 환경변수 `NODE_PATH`, `CHROME_PATH`, `PYTHON_PATH`로 지정하세요.

- 로컬 실행: `python -m http.server 8000 --bind 127.0.0.1` 후 로컬 주소 접속
- 전체 시험(Windows): `powershell -ExecutionPolicy Bypass -File tests/run.ps1`
- 공개 파일·엑셀 단위 시험: `node --test tests/public.test.cjs tests/export.test.cjs`
- 브라우저 시험: `node --test tests/browser.test.cjs` (직접 실행이 막히면 `tests/run.ps1`의 별도 Chrome 프로필 방식 사용)

자동 시험은 입력 유실·조합 Enter·저장 실패·날짜·XLSX 문자열 셀·클립보드 실패·7일 경계·음성 오류·늦은 Wake Lock·오프라인을 확인합니다. 시험 결과물은 `.test-output/`에만 두고 공개하지 않습니다. XLSX 검증은 메모리에서 수행하며 저장소에 엑셀 견본을 넣지 않습니다. `scripts/build_punch_xlsx.py`는 일반화된 PC용 양식 참고 자료이며 앱 실행에는 필요하지 않습니다.

**실기기 필요:** iPhone Safari·홈 화면 실행, Android Chrome·Samsung Internet의 키보드 가림·안전 영역, 실제 음성 인식과 전화 후 복귀, 파일 받기·열기, 오프라인 재실행.

## GitHub Pages 공개

공개 파일만 새 저장소 `field-punch-list`에 올리고 Pages의 공개 브랜치 루트(`/`)를 선택합니다. `.nojekyll`을 포함하므로 별도 빌드나 패키지 설치가 필요 없습니다. 실제 입력 데이터와 엑셀은 커밋하지 않습니다. 서비스 워커는 이 앱 범위의 자원과 캐시만 관리합니다. 기능 수정 시 `sw.js`의 캐시 버전도 올려야 합니다.


## 2026.09.22.2 사용성·안정성 개선

한 현장 사용과 음성 자동 등록을 유지합니다. 음성 자동 등록 후 최근 등록에서 바로 수정할 수 있습니다. 목록 표시 방식은 아래 2026.09.23.1 개선 내용을 참고하세요.

- **바로 수정:** 최근 등록 또는 목록 항목을 누른 뒤 수정으로 동·호수·위치·공종·내용을 고칩니다. 코어는 수정한 호수로 다시 계산하고 최초 입력일은 유지합니다. 수정 후에는 엑셀을 다시 받으세요. 수정 중 음성 인식은 잠시 멈췄다가 창을 닫으면 다시 듣습니다.
- **삭제 되돌리기:** 항목 삭제, 최근 등록 삭제, 전체 비우기 직후 10초 안에 복구할 수 있습니다. 가장 최근 삭제 작업만 복구하며 새로고침 후에는 복구하지 않습니다. 만료된 항목은 되살리지 않습니다.
- **세대 이동:** 동을 바꾸면 호수를 다시 정합니다. 초안이 있으면 현재 세대에 등록 후 이동, 새 세대로 내용 옮기기, 계속 작성 중에서 선택합니다. 이전 세대의 늦은 음성 결과는 받지 않습니다.
- **한 창 편집:** 같은 브라우저에서 동시에 연 창 중 하나만 편집합니다. 다른 창은 읽기 전용이고, 편집 창을 닫고 새로고침하면 이어서 사용할 수 있습니다. 오래된 상태로 덮어쓰려 하면 저장을 멈추고 안내합니다. 이 창의 기록은 엑셀로, 초안은 따로 복사한 뒤 새로고침하세요.
- **브라우저 지원:** 안전한 한 창 편집에는 Web Locks API가 필요합니다. 지원하지 않으면 읽기 전용으로 안내하며, 기존 기록은 엑셀로 받을 수 있습니다. 기기·브라우저 간 동기화 기능은 아닙니다.
- **설정 검사:** 공백·중복 항목과 잘못된 코어 구성을 거절합니다. 기록이 남은 상태의 현장명 변경은 기존 기록에도 새 이름이 적용됨을 확인받습니다. 다른 현장으로 쓰려면 엑셀로 받고 목록을 비운 뒤 설정하세요.
- **긴 입력:** 엑셀 셀 한계인 32,767자를 넘는 값은 등록을 막고 초안을 남깁니다. 기존 과다 길이 기록은 목록에서 수정한 뒤 엑셀로 받을 수 있습니다.

업데이트할 때는 기존 기록을 엑셀로 받고 다른 펀치리스트 창을 닫은 뒤 **저장 후 새로고침**을 사용하세요. 새 버전 표시가 `2026.09.23.3`인지 확인합니다. 이전 버전 창은 새 저장 보호 기능이 없으므로 함께 편집하지 마세요.

**실기기 필요:** iPhone Safari·홈 화면과 Android의 한 창 편집, 수정 창의 키보드·스크롤, 자동 음성 등록→수정 후 재개, 엑셀 받기·열기, 오프라인 재실행. 실제 기기 검증 결과로 표현과 동작을 조정합니다.


## 2026.09.23.1 많은 기록을 빠르게 찾기

- 휴대폰 목록은 위치·공종과 내용 두 줄로 표시합니다. 항목을 누르면 생략 없는 내용과 점검일·코어·파일 받기 요청 정보를 확인하고 수정·삭제할 수 있습니다.
- 처음에는 **현재 세대**의 기록을 보여 줍니다. **전체**에서는 동·호수별 건수를 보고 한 세대씩 펼칩니다. 위쪽의 전체 건수는 검색 중에도 유지됩니다.
- 동·호수·위치·내용 검색과 공종 선택을 함께 쓸 수 있습니다. 공백으로 나눈 검색어는 모두 포함하는 기록을 찾습니다. 세대 이동 후에도 검색 조건은 유지되며 **검색 초기화**로 지웁니다. 조회 선택은 새로고침하면 초기화됩니다.
- 세대 안에서는 최근 입력부터 **20건 더 보기**로 이어 봅니다. 전체 조회의 세대 목록도 20세대씩 표시합니다. 목록을 펼쳐도 현재 입력할 동·호수는 바뀌지 않습니다.
- 휴대폰에서 아래로 스크롤하면 입력 중인 동·호수만 작은 상단 표시로 남습니다. 내용과 위치·공종은 큰 상세 창에서 확인할 수 있습니다.
- **전체 엑셀 받기·엑셀로 복사·전체 비우기**는 조회 조건과 무관하게 전체 기록에 적용됩니다. 엑셀의 동 → 코어 → 층 내림차순 → 호수 정렬은 유지합니다.

실행 확인: 가상 기록 1,000건의 20건 표시·검색·공종 선택·세대별 접기, 필터 안에서 정확한 항목 수정·삭제·복구, 전체 1,000건 XLSX·복사, 읽기 전용 창의 조회. Chrome 모바일 화면에서 짧은 기록 7건 이상 표시, 가로 넘침 및 상세 창을 확인했습니다.

**실기기 필요:** iPhone Safari·홈 화면과 Android에서 실제 글자 크기·스크롤·키보드, 목록 → 상세 → 수정 복귀, 음성 등록 중 조회, 100건 이상 현장 기록의 찾기 편의성. 자동 시험은 실제 휴대폰 사용을 대신하지 않습니다.


## 2026.09.23.2 말한 내용을 우선 보존

- **원문 우선:** 음성 인식기가 받아쓴 문장을 자동 등록합니다. 문장 내부의 공백·줄바꿈·숫자·치수·방향·부정 표현은 유지하며 앞뒤 공백만 정리합니다. 유사 발음으로 다른 단어를 추정하거나 단위를 자동 변환하지 않습니다.
- **분류와 본문 분리:** 동·호수·위치는 버튼에서 정한 값이 유지됩니다. 공종은 아래 2026.09.23.3의 자동 분류 또는 직접 선택을 사용합니다. 위치·공종 단어를 본문에서 빼지 않습니다. `취소`, `삭제`, 세대 번호도 음성 명령으로 실행하지 않고 내용으로 기록합니다. 삭제는 화면 버튼을 사용하세요.
- **선택하는 보정:** `겸출 → 견출` 같은 제한된 제안을 최근 등록의 **보정 확인**이나 항목 상세에서 보여 줍니다. 초기에는 자동으로 바꾸지 않습니다. 뜻이 맞는 제안만 눌러 현재 항목에 적용합니다.
- **기억은 별도 선택:** **다음에도 같은 단어를 자동 보정**을 체크한 뒤 적용한 규칙만 이 기기에 기억합니다. 단어 전체가 일치할 때만 적용하며, `겸출부`나 `겸출1`의 일부를 바꾸지 않습니다. 직접 입력과 자판 마이크 입력에도 같은 규칙을 적용합니다. 직접 수정한 문장은 다시 자동 보정하지 않습니다.
- **원문 확인·복원:** 새 기록은 등록 전 입력과 적용한 보정 이력을 함께 보존합니다. 상세의 **입력·보정 전 문장 보기**에서 확인하고 되돌릴 수 있습니다. 이전 버전의 기록은 최초로 보정하기 직전의 내용을 남깁니다. 기록에 남지 않은 과거 발화를 복원하거나 녹음을 보관하는 기능은 아닙니다.
- **기억 지우기:** 화면 아래 **확인한 보정 표현**에서 규칙을 지울 수 있습니다. 이미 작성한 내용은 바꾸지 않습니다. 원문으로 되돌려도 기억한 규칙은 별도로 지워야 다음 입력에 적용되지 않습니다.
- 원문·이력은 해당 기록과 함께 7일 보관 규칙을 따릅니다. 기억한 보정 표현은 세팅으로 유지하며 기기 간 공유하지 않습니다. 보정·수정·복구해도 최초 입력일과 만료일은 늘어나지 않습니다. 엑셀에는 현재 화면의 최종 내용만 출력하며, 수정·보정 후 다시 받으세요.

저장 형식 3은 기존 키 `punchlist.v2`를 유지하고 `speechRules`, 기록의 `inputText`, `inputKind`, `correctionLog`를 추가합니다. 잘못된 규칙이나 모르는 버전은 원본을 덮어쓰지 않고 원본 받기를 제공합니다. 보정은 로컬 `speech.js`에서 처리하며 새 외부 서비스나 비용은 없습니다.

실제 발화가 인식 단계에서 틀렸거나 누락된 경우는 이 기능만으로 모두 복원할 수 없습니다. 실제 오류 예시를 확인해 제안 사전을 보완합니다. **실기기 필요:** iPhone 자판 마이크와 앱 마이크 각각의 받아쓰기, 보정 확인→음성 재개, 실제 현장 소음에서 문장 보존과 수정 편의성.


## 2026.09.23.3 공종 자동 분류와 확인사항

- **항목마다 판단:** 자동 분류를 선택하면 대상과 보수 내용이 함께 드러나는 문장만 공종을 넣습니다. 예를 들어 벽지 이음부 들뜸은 도배, 창짝 개폐 불량은 창호로 분류합니다. 직전 항목의 분류는 다음 항목에 넘기지 않습니다. 말한 내용은 그대로 남깁니다.
- **애매하면 확인:** 균열·오염처럼 대상이 불명확하거나 여러 공종 단서가 섞이면 공종을 비웁니다. 목록의 **공종 확인필요만 보기**로 모아 확인하고, 항목 수정에서 **직접 지정**으로 공종을 정하세요. 이 필터는 현재 세대·검색 조건과 함께 적용됩니다. 전체 기록을 보려면 전체와 검색 초기화를 사용하세요.
- **직접 선택 우선:** 공종 버튼으로 고른 값은 이후 입력에도 유지합니다. 자동 분류로 돌아가려면 자동 분류를 누르세요. 기존 공종과 기록은 자동으로 다시 분류하지 않습니다.
- **수정·보정:** 자동 분류 항목은 내용 수정, 사용자가 승인한 보정, 원문 복원 시 다시 판단합니다. 직접 지정한 항목은 내용이 바뀌어도 공종을 유지합니다. 최초 입력일과 보관 기간은 그대로입니다.
- **엑셀:** 기존 A–G 열 뒤에 H열 **확인사항**을 추가합니다. 공종이 비어 있으면 **공종 확인필요**를 노란색으로 표시하고 같은 이름의 별도 시트에 모읍니다. 전체·공종별 시트와 복사는 모두 8열입니다. 자동 분류된 공종도 현장에서 확인하세요. 인쇄는 A4 가로입니다.
- **엑셀 수정:** H열을 필터로 골라 공종을 수정한 후 확인사항을 지우세요. 받은 파일의 수정은 앱이나 다른 시트에 자동 반영되지 않습니다. 앱에서 수정하고 새 엑셀을 받는 방법도 있습니다.

분류는 로컬 `trade.js`의 제한된 규칙입니다. 외부 AI 서비스나 추가 비용은 없습니다. 정확도는 실제 현장 문장으로 확인해야 합니다. 저장 형식 4는 자동·직접 지정 방식과 판단 이유를 추가하며 기존 원문·보정 이력을 유지합니다. **실기기 필요:** 연속 음성 중 공종 생략·혼합, 직접 지정과 자동 전환, 확인필요 필터, 휴대폰 엑셀의 H열 필터와 저장·열기.
