자동 분류는 대상과 보수 내용이 분명할 때만 공종을 넣습니다. 부정·추측 표현이나 애매한 조합은 공종 확인필요로 남깁니다. 수정에서 직접 지정할 수 있습니다. 기존 기록은 자동으로 다시 분류하지 않습니다.

엑셀 H열 확인사항의 공종 확인필요를 필터로 찾으세요. 해당 칸은 노란색이며 별도 공종 확인필요 시트에도 모입니다. 엑셀에서 고친 값은 앱이나 다른 시트에 자동 반영되지 않습니다. 엑셀에서 직접 고쳤다면 확인사항도 지우거나, 앱에서 수정 후 다시 받으세요. 인쇄는 A4 가로입니다.

  1. 동 버튼과 숫자판으로 호수를 정하고 이동을 누릅니다.
  2. 위치를 고르고 공종은 자동 분류 또는 직접 선택합니다. 직접 선택한 공종은 다음 입력에도 유지됩니다.
  3. 내용을 입력하고 한 줄 추가를 누르거나 마이크로 말합니다.
  4. 엑셀 받기를 누르고 파일 앱·다운로드 폴더에서 파일을 확인합니다.
